2. **控制台「🏠 恢复到主页」按钮**（桌面版 + 手机版都有，在「视频」行下面）：
   - 点一下 = 停掉当前推理 + 退回 op 主页（就像你说的：切出停止现在的推理，退出到 op 主页）。
   - 栈没在跑时点它 = 直接帮你把 op 主页起起来。
   - 之后想继续看：导入视频 / 再开 slowroads，都会自动离开主页模式。
3. **默认状态 = op 主页**：打开控制台（桌面版或网页版）时如果没开 slowroads，左上角显示的就是 op 主页（op 熄火待机，一直亮着）。
4. **全端统一**：桌面版、网页版、手机版控制台行为一致（左上角自动切换 + 恢复到主页按钮）。
5. 「slowroads 自动驾驶」按钮、双 app 生命周期规则：**没动**（按之前约定）。

## 怎么用（验收流程）

1. 双击 **「openpilot slowroads」**（访达 → 应用程序，或 Spotlight 搜 slowroads）。
   - 屏幕上会先出现游戏窗口（slowroads 开始页），然后控制台左上角自动切成游戏画面；
     40 秒左右 op 启动完成后，状态行会显示「已接入 openpilot（实时源）」。
   - 注意：游戏窗口**别最小化、别被完全盖住**（macOS 会把后台窗口的渲染冻住，op 就看不到新画面）。
2. 关掉游戏窗口 → 控制台左上角自动切回 op 画面，op 回主页。
3. 在任何时候点控制台里的 **「🏠 恢复到主页」** → 停推理、回主页。
4. 网页版 / 手机版同一行为（改完记得刷新一次页面）。

## 技术上怎么实现的（给以后接手的人）

- App 打开 → 启动器每 2 秒写心跳 `slowroads_app.json` → 控制台后端 SSE 报 `slowroads.open`。
- 心跳在 + 不在主页模式 → 前端把左上角画面流从 `/api/opstream`（op 画面）切成 `/api/gamestream`（游戏实时帧）。
- 「恢复到主页」= 暂停画面源（推理停）+ 写 `home.flag` → 假车桥接熄火（ignition=False）→ op 进 offroad → 自动渲染 op 主页。
- 「__HOME__ 启动模式」= 不播视频、以一张深灰占位帧起栈 + 熄火待机 → 就是「控制台打开但还没干活」的默认样子。
- 新增端点：`GET /api/gamestream`（游戏画面流）、`POST /api/home`、`POST /api/slowroads_reconnect`；手机版 `GET /api/gameframe.jpg`。

## 已知边界（如实说）

- 接入需要约 40 秒（op 全栈重启一次）——这是原来就有的启动时间，没法绕过。
- 游戏窗口被完全盖住/最小化时 macOS 会冻结它的渲染 → op 画面源停更（控制台会提示「画面源已冻结」）——把窗口切回前台就恢复。
- 控制台页面改完需要刷新一次才生效（桌面版 app 重开、网页版刷一下）。
