## M7 · ANE（CoreML mlpackage）加速 ✅ 已完成（2026-09-28）

> 目标：把驾驶模型（supercombo）从 tinygrad/Metal 换到 **Apple 神经引擎（ANE）**，用 CoreML mlpackage 运行。
> 预期收益：modeld CPU 38% → 个位数；模型推理更快（现在 13.6ms/帧，其中 GPU 内核约 10.6ms）。

### 为什么值得做

- ANE 是专用硬件：跑卷积几乎不占 CPU（现在 modeld 占 0.38 核）
- 这是这台 8GB M1 上**唯一还能大幅降占用**的手段（CPU 侧已优化到位）

### 已知风险（诚实列出）

| 风险 | 说明 | 对策 |
|------|------|------|
| 转换保真度 | coremltools 9 已移除 ONNX 前端 | 用 coremltools 7.2 直转 ONNX；失败再走 ONNX→PyTorch→CoreML |
| 数值差异 | ANE 是 fp16 计算，输出**不会**逐字节一致 | 验收标准改为「最大绝对误差 < 阈值 + 演示里车道线/路径位置正常」 |
| 算子支持 | 卷积主干 ✓；循环头部分算子可能落到 GPU/CPU | 用 MLComputePlan 查 ANE 命中率，逐算子处理 |
| 依赖隔离 | coremltools 7.2 需要 numpy<2，而项目 venv 是 numpy 2.5（不能动） | 转换用**独立 venv** `~/op项目of all/ane-convert/.venv`（py3.11 + coremltools 7.2） |
| 数据搬运 | warp（透视变换）在模型前，ANE 版要么保留 tinygrad warp 要么一起转 | 先只换主模型，warp 留在 Metal，量测搬运开销再决定 |

| 项 | 结论 |

| Python 3.13+ | 已移除 `cgi` 模块 → 不能用标准库解析 multipart |

**关键技术决策**

1. **前缀行为不赌，后端做归一化**
   `--set-path` 是否剥掉 `/op` 前缀存在版本差异。应对：后端同时接受 `/op/...` 与 `/...`（检测到已知前缀就剥），前端一律用**相对 URL**。两种情况都能跑，不依赖行为假设。

2. **手机端取流用「JPEG 轮询」，不用 MJPEG**
   MJPEG 在移动端弱网/后台易卡死，且无法控制画质与帧率。轮询 `?t=` 可精确控帧率+质量、断了自恢复。
   桌面版继续用 MJPEG，**不改**。

3. **上传走裸 body 流式写盘，不用 multipart**
   Python 3.13+ 无 `cgi`，自写 multipart 解析器处理 700MB 文件易踩坑。
   方案：`POST /api/upload?name=x.mp4`，body 即文件原始字节，8KB 块边收边写盘；零依赖、支持大文件、前端可用 XHR 显示进度。

4. **鉴权用「登录页 + 签名 Cookie」，不用 HTTP Basic**
   Basic 在手机浏览器体验差、无法登出、每路流都带凭据。
   方案：`/login` → 校验密码 → 下发 `HttpOnly` + `Secure` + `SameSite=Strict` 的 HMAC 签名 Cookie（30 天）。密码存 600 权限文件。

5. **导出改为「下载到手机」**，原「保存到 Mac 桌面」的接口保留不动。

6. **触控点击坐标换算**：按 `<img>` 的**实际渲染尺寸**归一化后再调 `/api/click`（注意画面有 letterbox 留边，不能直接用触控点像素）。

7. **手机流模式（新增，只加不减）**：宽 960 + quality 60 + 10fps ≈ **150~250KB/s**（原图直转是 1.1MB/s）。

8. **导入方式改用「网页内文件浏览」替代原生框**（2026-09-29 你定的）
   新增 `GET /api/fs?path=`：列目录 + 视频文件（名称/大小/时间），前端面包屑 + 列表，点文件即导入。
   - 好处：**手机上远程也能选文件**，不再依赖 Mac 屏幕前的人，也不受锁屏影响
   - 安全边界：`realpath` 必须落在**允许根目录**内，禁止 `..` 穿越（越界一律 403）
   - 允许根（拟）：项目目录 `~/op项目of all/op方向的辅助驾驶方案`（含 `测试素材/`）+ 快捷入口 桌面 / 下载 / 影片
   - 大文件（>200MB）点击后二次确认，避免误点
   - 原生框 `/api/pick` **保留不动**（桌面版继续用，互不影响）

### 坑（本次踩到并记录）

1. **macOS 没有 `setsid`** —— 旧 `restart_console.sh` 里的 `setsid nohup ...` 一直静默失败，后端实际是靠桌面版 app 的看门狗救回来的。改用 Python `subprocess.Popen(..., start_new_session=True)`。
2. **`bash -c "bash x.sh"` 会 exec 优化** —— 外层 bash 直接 exec 内层命令，「脚本的父进程」不是你以为的那个。测试假 app 必须写 `bash -c "bash x.sh & wait"`。
3. 状态页由后端提供 —— 后端挂了页面加载不出来，所以外壳必须捕获加载失败并显示兜底页（带重试按钮）。
4. 报错抓取要**滤掉 traceback 噪音**：`ConnectionResetError` 及其伴随行（`Traceback (most recent call last)`、`Exception occurred during processing of request from`）不算报错，否则报错区永远刷屏。
