# 「闪固定画面」跳变 — 根因报告与修复计划

> 2026-09-30 · 汇总两天调查（09-29 注入实验 + 09-30 三连跑对照）+ 原始抓包数据
> 主角现象：op 覆盖层跳到**固定幻觉**（4 条车道线全亮 + 一辆不存在的车）

## 一、现象（精确描述）

- **画面特征**：4 条车道线全部亮起（"固定路线"）+ 约 69 米处一辆不存在的车（"固定车"，黄色前车标记）
- **两种形态**：闪动（快速进出，几帧）／长时间锁定（几十秒不动）
- **危害**：假车诱发莫名刹车、方向修正（slowroads 没有别的车 → 检出车=幻觉）；还会误触发 FCW/AEB（红闪+音效）
- **精确指纹**（跨小时、跨多次事件逐字节一致 = 循环网络的固定点）：
  - laneProbs = `[0.85, 0.96, 0.90, 0.22]`
  - leadProb ≈ `0.54 @ 69.31 m`
  - （另一状态值：定格视频曾锁 `[0.154, 0.513, 0.403, 0.109]`——输入相关，见附注⑤）

## 二、根因 = ANE（CoreML fp16）推理引擎 —— ✅ 已用实验钉死

| # | 实验 | 结果 |
|---|---|---|
| 1 | 同一素材、只换引擎（用户实测） | ANE=跳 / Metal=不跳 |
| 2 | 抓包（去重全关 + ANE + 素材视频） | 幻影车 prob 0.536 @ 69.3m 出现 20 帧，**播放中**（fid=53）就出现——不是定格后才跳 |
| 3 | 版本对照（bisect） | 1.0（09-28，只有 Metal）不跳；1.1（09-27）不跳；今晚版（09-29，ANE 默认）跳 |
| 4 | 去重/连贯性门全关 | **照跳**（数据实锤）→ 排除相机侧嫌疑 |
| 5 | 注入实验（受控帧序列） | 稀疏跳帧、慢爬 = 漂移燃料；快速大变化 = 不漂 |
| 6 | **三连跑对照（2026-09-30，决定性）** | 同素材同代码、只换"谁来算"：GPU **0** 命中 / CPU **0** 命中 / **ANE 命中**（mvFrame 63 精确指纹 + 熔断日志实锤）|

**三连跑明细**：`跳变调查数据-20260929/三连跑-20260930/三连跑结果.md`
- ②③ 用**同一个 mlpackage、同一套 runner**，唯一区别 = 计算单元（CPU_ONLY vs CPU_AND_NE）→ **触发者 = ANE 芯片的 fp16 执行路径**；转换/接口/模型文件本身全部排除
- run③ 命中值逐字节复现历史指纹：`[0.8493, 0.9606, 0.9031, 0.2229]` + `0.5362 @ 69.31m`
- 命中发生在模型启动后第 5 帧（冷启动轨迹）；CPU/Metal 全片 1236–1283 帧 **0 命中**
- 今天命中仅 1 帧（熔断立即压掉）；历史长时版本 = 游戏 13 段/14 分钟、素材 20 帧 → 持续劣化输入下会长时间驻留
- **复验（09-30 晚）**：ANE 再加跑一轮（同素材）→ **4 次命中**（带「重新校准」标记；用户自测轮 3 次）——命中**稳定复现**（1 / 4 / 3 次）；Metal / CPU 依旧 0。⚠ 观察：重校准模式下命中偏多（3–4 次 vs 预置标定 1 次），待验证

**机制**：模型是**循环网络**（上一帧的"记忆"回灌下一帧）。同一输入序列、同一模型文件——**ANE 的 fp16 数值轨迹会滑进固定点，CPU/GPU 的轨迹不会**。具体是哪些算子的精度差贡献最大，留到 2A 阶段定位。

## 三、别混淆：4 个长得很像的现象

| 现象 | 是什么 | 原因 | 现状 |
|---|---|---|---|
| ① 固定幻觉跳变（4 线全亮+假车，闪动/锁定）| **本报告主角** | ANE fp16 引擎 | 待修（计划见下）；当前用 Metal 规避 |
| ② 画面源被"掐死"（模型 0 帧）| 去重把 57.8fps 素材的相邻帧当"重复帧"全丢 | 去重 v3 的已知边界（针对游戏 2-7fps，不适用 60fps 视频）| 已知；`OP_CAM_SKIP_STATIC=0` 可关 |
| ③ 游戏卡顿/切后台时的"闪动" | 输入变成"没有新信息" → 漂移**燃料** | 游戏渲染卡顿 + App Nap | 去重 v3 + 连贯性门已拦（对游戏有效）|
| ④ 控制台前车图标"红闪" | AEB 指示器**功能**（触发时闪烁）| 不是 bug | 正常 |

> 附注⑤：视频播完定格后输出保持最后一帧（Metal 也会）——那是"输入没有新画面"的正常行为，不是幻觉跳变；去重生效后连这个都停了。
> 关系：①②③④ 里，**只有 ① 是引擎的问题**；②③ 是相机/输入侧，修复只治"燃料"；④ 是功能。
